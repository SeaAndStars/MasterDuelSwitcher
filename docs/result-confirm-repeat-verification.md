# 多次结果确认验收

## 使用规则

本包结果确认包含首次最多30次：首次立即点击，之后间隔200、400毫秒递增并封顶600毫秒。每次都重新核验两帧结果页与当前按钮，独立按下并完整松开；返回原卡包详情后立即停止本包确认。实际间隔包含识别与输入耗时。

按F8或停止按钮结束。原60秒等待、失焦恢复及免费购买门禁保留；达到30次后只观察，不追加确认。鼠标输入仍先等待40毫秒、按住80毫秒后松开。

退出旧版工具，运行 `MasterDuelSwitcher-result-repeat.exe`，在游戏卡包详情页开始。Debug日志的确认序号、RequiredIntervalMilliseconds与AttemptLimit分别记录次数、间隔和上限。

全量覆盖缺口仍仅为保留游戏而延后的 ResourceProcessTests 对应5行、2分支，没有新增生产排除或降低100%门槛。独立审查确认购买、窗口、Native与返回后停止门禁保持。
