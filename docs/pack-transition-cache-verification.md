## 本轮修补

- 第26包已点击入口但费用OCR暂空：同包详情只等待独立免费弹窗，不追加入口点击，不按该空结果购买或计数。
- 购买退出动画移动按钮：最后成功动作仍为免费购买时等待弹窗消退，不重复购买、不续期。发送动画跳过后重新出现购买框仍拒绝。
- 购买过渡单帧标题误字、字形签名变化：先双帧复核；复核帧恢复原包则继续，稳定另一包仍结束。标题精确比较和完整签名规则保持，不用相似卡图接受文字身份。
- 左侧感叹号：完整类别改在原始灰度像素定位，类别仍要求0.92，分隔符独立核验，标题取样跟随真实锚点。
- 首次匹配坐标：当前几何下优先复核原尺度、原边界四像素内区域；通过后复用首次中心，失败恢复完整扫描。窗口句柄、客户区宽高或屏幕原点变化清缓存。费用OCR及宝石证据每帧重新读取。

F8、三秒失焦恢复、60秒无进展期限、结果确认30次／600毫秒上限及200包上限保留。已观察结果后冻结旧Skip、原包双帧返回计数和下一包保护保留。

## 启动与日志

1. 停止旧任务并关闭旧工具，打开本包 `MasterDuelSwitcher.exe`，按Windows正常UAC提示允许启动。
2. 游戏使用简体中文，先返回卡包详情页；若停在弹窗、动画或结果页，先返回详情再启动新一轮。
3. 点击“开始免费开包”；F8或停止按钮结束。首次完整匹配后局部辅助核验自动启用，无需设置。
4. 系统日志位于 `%LOCALAPPDATA%\MasterDuelSwitcher\logs`，文件可能滚动为 `debug-日期_001.log` 等；诊断截图位于 `free-pack-diagnostics`。数据库仍在系统数据目录，包目录不保存账号数据。

新增Debug事件：`FreePackTemplateCacheHit/Fallback/GeometryInvalidated`、`FreePackRecognitionTiming`、`FreePackPurchaseTransitionWaiting`、`FreePackPurchasedDialogDismissing`、`FreePackTransitionIdentityReview/Restored`。可用RunId、FrameSequence和ActionSequence串联费用门禁、识别、输入及后续页面。
