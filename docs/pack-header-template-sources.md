普通类别源 SHA256：`4AFB8D4CBEEFFD12AB7379F2F095FE6016CE6C568F295A2B4F4D297246A5FAD6`。与用户提供的 `codex-clipboard-830419a2-8ac6-4616-806f-758b4d95cc73.png` 原图一致；它是付费购买弹窗，其背景类别为“普通卡包｜”。

普通详情回归使用真实类别模板移植到原秘密详情的派生夹具，仅替换类别联合区域，原标题、详情菜单及下一包保持原位；它不作为完整普通详情的现场录制证据。完整普通详情与新版游戏循环的现场验证仍待完成。

单个整体模板即使缺竖线仍可能得到高相关评分，因此联合匹配后单独核验框内末端分隔符；该区域不扩展到右侧标题，标题首字及内部合法汉字“丨”继续保留。

分隔符的真实竖线为 `270 / 84 / 2 / 35`；七像素模板保留左右背景并缩短纵向留白，使原始灰度搜索可吸收联合锚点降采样造成的位置取整。搜索右界仍止于联合框，保留标题区域之外的界面分隔符约束。
