## 使用

先停止自动开包并退出旧工具，启动本候选EXE。在卡包详情页开始；红色感叹号可出现或消失。Debug日志FreePackTitleCacheHit表示当前字形核验后的标题复用，FreePackTitleCacheRefreshed表示重新读取，FreePackHeaderMatched/Rejected记录类别、分隔符及拒绝原因。
