## 使用

停止旧工具自动开包并退出旧工具，运行 `artifacts/publish/header-ocr-live/MasterDuelSwitcher.exe`，在 Windows UAC 允许启动。游戏停在卡包详情页，工具导航至“免费开包”并点击开始。F8 随时停止；失焦三秒后恢复原游戏窗口。

`FreePackTitleRead` 保存每次标题原生文字及区域；`FreePackTitleRetry` 仅记录空结果的一次采样重读。两次空结果继续等待有效画面，不放行未知购买。
